# Progression & Equipment

## Time Investment Goals

### Target Experience
- **40 hours minimum** for meaningful playthrough
- **200+ hours potential** for deeply engaged players
- **Unlocking all characters = completionist goal** (not required for base experience)

### First Playthrough
- 45 battles at 10 minutes each = 450 minutes = **7.5 hours**
- Learning, exploring, slower pace
- Introduction to all systems

### Subsequent Playthroughs
- **Minimum 4 playthroughs** to unlock core character set
- 4 × 7.5 hours = **30 hours** for core completion
- Optimized routes, faster completion
- Experimentation with different paths

### Completionist
- 30+ characters to unlock
- 6 different starting points
- Multiple story branches
- **100+ hours** for true completion
- Plus Infinite Mode for hundreds more hours

## Equipment System

### Shops
- **Strategically placed throughout storyline**
- Different shops sell different gear
- **Deterministic inventory** - no random items
- Shop locations part of strategic planning
- Choosing story path to reach specific shop

### Item Availability
- **Shops**: Currency-based purchasing
- **Quests**: Rewards for completion
- **Battle Loot**: Drops from battles

### Strategic Equipment Choices
- Cannot access all shops in single run
- Cannot complete all quests in single run
- Getting specific character + their best gear = challenging
- Optimizing one character limits optimization of others
- Trade-offs between character recruitment and equipment access

### Central Inventory System
- Upon storyline completion: **Equipment goes to central inventory**
- Can re-equip characters from central pool
- Enables optimization in New Game+ and Infinite Mode
- Rewards multiple completions with same character

- Quest rewards
- Battle loot

- Advanced crafting unlocked
- Equipment enhancement/upgrading
- More difficult challenges drop better materials

## Skill Progression

### During Story
- 5 skills per character (1 per chapter)
- Skills level up through use
- Choose which skills to improve post-battle
- Limited progression per playthrough

### Post-Story
- Continue skill leveling in Infinite Mode
- Refine builds
- Master advanced synergies
- No level cap (or very high cap)
