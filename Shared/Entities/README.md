# Entities Project

**Dependencies**: Main, Data, Timeline, Factions

## Responsibilities

- All living entities: Character, PlayerCharacter, NonPlayerCharacter, Mob, Creature, Monster
- Pure skill-based progression: No classes, only skill advancement
- Mutations/transformations: Permanent character changes
- Companion systems: Pet/ally management and leadership abilities
- Polymorph systems: Temporary creature transformation
- AI systems for NPCs and creatures

## Key Classes (Planned)

- `Character` - Base character class
- `PlayerCharacter` - Player-controlled character
- `NonPlayerCharacter` - NPCs with dialogue and behavior
- `Mob` - Mobile hostile entities
- `Creature` - Wildlife and neutral entities
- `CompanionManager` - Pet and ally management
- `SkillProgression` - Pure skill-based character advancement
- `EntityAI` - Behavior systems for non-player entities

## Content

Entity sprites, portraits, animations, transformation effects, skill icons
