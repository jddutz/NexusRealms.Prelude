# Timeline Project

**Dependencies**: Main, Data

## Responsibilities

- Global timeline: Events spanning all realms
- Turn-based event system: Events triggered by player actions/turns
- Event prevention/alteration: Player agency in changing outcomes
- Faction evolution: Cross-realm faction relationship tracking
- Meta-knowledge system: Player learning and event prediction
- Consequence engine: Complex cascading effects

## Key Classes (Planned)

- `Timeline` - Core timeline management
- `TimelineEvent` - Individual events with triggers and consequences
- `WorldState` - Current state tracking across realms
- `ConsequenceEngine` - Handles event outcomes and cascading effects
- `MetaKnowledge` - Player learning and event prediction system
- `EventScheduler` - Turn-based event scheduling

## Content

Timeline data files, event definitions, consequence trees, meta-knowledge templates
