# GameAssets Project

This project contains the game assets and content management system for NexusRealms. Prelude.

## Namespace

`NexusRealms.Prelude.GameAssets`

## Purpose

- Game asset definitions (textures, sprites, fonts, sounds)
- Content loading interfaces
- Asset management services
- Presentation layer resources

## Key Components

- `IContentService` - Interface for content loading services
- Various game assets organized in subdirectories
