# Maps Project

**Dependencies**: Main, Data, Environment

## Responsibilities

- Procedural generation: Turn-based dungeon/level generation
- Line of sight/FOV: Vision and fog of war systems
- Scale variation: Different map scales (tactical vs strategic)
- Teleportation systems: Magical transportation mechanics
- Water/swimming: Aquatic movement and mechanics
- Spatial indexing: Turn-based spatial optimization

## Key Classes (Planned)

- `Map` - Core map representation
- `MapGenerator` - Procedural generation systems
- `TileGrid` - Grid-based map structure
- `FieldOfView` - Line of sight and fog of war
- `SpatialIndex` - Efficient spatial queries
- `TeleportationSystem` - Magical transportation
- `AquaticSystem` - Water and swimming mechanics

## Content

Tilesets, terrain textures, environmental art, water effects, teleportation visual effects
