# Realms Project

**Dependencies**: Main, Data, Maps, Timeline, Factions

## Responsibilities

- Realm progression: Increasing difficulty across realms
- Inter-realm travel: Movement between worlds
- Realm-specific features: Unique mechanics per realm
- Progressive challenge: Scaling difficulty without level scaling
- World state coordination: Managing state across multiple realms

## Key Classes (Planned)

- `Realm` - Individual realm/world representation
- `RealmManager` - Multi-realm coordination
- `RealmProgression` - Difficulty scaling and progression
- `InterRealmTravel` - Portal and travel systems
- `RealmFeatures` - Unique mechanics per realm
- `WorldStateCoordinator` - Cross-realm state management

## Content

Realm-specific graphics, portal effects, world maps, realm transition animations
