# Items Project

**Dependencies**: Main, Data, Entities

## Responsibilities

- Equipment, consumables, tools, quest items, currency
- Durability & degradation: Item wear and maintenance
- Identification system: Unknown item mechanics
- Cursed items: Negative effect items
- Spell components: Material-based magic system (no mana)
- Alchemy & cooking: Item combination and crafting
- Legacy items: Items persisting across characters

## Key Classes (Planned)

- `Item` - Base item class
- `Equipment` - Wearable items (weapons, armor, accessories)
- `Consumable` - Usable items (potions, food, scrolls)
- `SpellComponent` - Materials for casting spells
- `Inventory` - Item storage and management
- `CraftingSystem` - Alchemy and cooking mechanics
- `ItemIdentification` - Unknown item discovery system
- `LegacyItem` - Cross-character item persistence

## Content

Item sprites, icons, effect graphics, crafting animations, identification visual effects
